# Northwind Identity Operations Demo

An original, clean-room portfolio demonstration of a resumable identity lifecycle workflow.

## Privacy and ownership

- Uses fictional task identifiers and synthetic organizational data only.
- Contains no employee, student, customer, or other personal information.
- Does not connect to Active Directory, Microsoft 365, SQL Server, or any external service.
- Contains no employer source code, branding, configuration, credentials, or infrastructure details.

## Features

- Operations overview and workflow health metrics
- Searchable provisioning queue
- New-hire, transfer, and termination workflow examples
- Waiting, retry, review, queued, running, and completion states
- Interactive task-stage inspection and simulated advancement
- Anonymous personnel-request intake
- Browser-local persistence and demo reset
- Exportable synthetic audit trail

## Run locally

Open `dist/index.html` in a browser, or serve the `dist` directory with any static web server.

## GitHub Pages

Publish the contents of `dist` from the repository's `main` branch using GitHub Pages. This project has no build step.
